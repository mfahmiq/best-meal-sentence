# The Best Meal You Ever Had

The one sentence about the best meal I ever had:

> At a plastic table in Yogyakarta, my grandmother's gudeg — jackfruit stewed for hours in coconut milk — arrived still steaming, and I ate three plates before I noticed the rain had stopped.

189 characters. The setup is a meal anyone can picture — a plastic table, a grandmother's gudeg, jackfruit stewed for hours in coconut milk, arriving still steaming. The turn is the eater's absorption: three plates gone before they noticed the rain had stopped. No claim that it was "the best", no cliche about melting in the mouth — the three empty plates and the unnoticed rain are the proof. It won an internal 16-candidate pairwise tournament judged on the published brief (see CANDIDATES.md).

## How to run

```sh
python3 main.py
```

This writes the sentence verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
